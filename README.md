# 🩺 DoctorNow - Doctor Appointment Booking System

**Live Site:** [DoctorNow Live](https://doctor-now-seven.vercel.app/)

## ✨ Key Features

- Browse and search 500+ verified doctors across multiple specialties
- Easy appointment booking with instant confirmation
- Secure JWT-based authentication with Google OAuth
- Personal dashboard to manage appointments and profile
- Fully responsive design optimized for all devices
- Real-time search and filtering functionality

## 🛠️ Tech Stack

**Frontend:** Next.js 16, React 19, Tailwind CSS, HeroUI, Framer Motion

**Backend:** Node.js, Express, MongoDB, Better Auth

## 🚀 Getting Started

```bash
# Frontend
cd client
npm install
npm run dev

# Backend
cd server
npm install
npm run dev
```

## 📁 Key Pages

- Home - Hero banner, top doctors, how it works
- All Appointments - Browse doctors with search
- Doctor Details - Doctor info and booking
- Dashboard - Manage bookings and profile
- Authentication - Login/Register pages
